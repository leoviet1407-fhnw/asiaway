## How staff set the weekly dish

**Service → Saturday dish.** Pick the Saturday, take or choose a photo, type the
name in all three languages, save. The photo is shrunk automatically, so a
picture straight off a phone is fine.

If no dish is set for a Saturday, guests simply do not see the special — they
still see Bánh Mì. Last week's dish is never shown again.
